# 学习与演进记录

BabySteps 从一个最小链上便签逐步演进为亲子成长产品概念验证。保留这份记录是为了
说明技术决策如何被验证，而不是把产品入口包装成课堂交付物。

## 演进路径

1. 用 Solidity 完成便签的读取、写入和清空，理解 call、交易广播和 receipt。
2. 使用 Hardhat 在本地测试合约，并部署到 Sepolia。
3. 通过 Etherscan 和 Sourcify 验证源码，让字节码与公开源码可核对。
4. 用 wagmi/viem 接入 React 和 MetaMask，处理网络、签名、确认与错误状态。
5. 加入活动冷却、双账本和赠送机制，同时限定隐私与非金融边界。
6. 将产品从合集仓库按 Git 历史拆分为独立仓库，建立独立测试与发布流水线。

## 关键认识

- 前端按钮不是安全边界，所有关键规则必须由合约再次校验。
- 区块链的“清空”不等于删除历史，因此输入之前必须按永久公开数据来判断。
- 可转积分与累计成长值承担不同语义，拆成两个账本能避免赠送破坏成长阶段。
- 自动构建只能证明代码可重复产出；真实链上交易和源码验证仍需要独立证据。
