# BabySteps Web3 Growth Marketplace Roadmap

The approved product spans five independently testable systems. Implement them in order so every phase leaves working software and a reviewable evidence trail.

1. **Contract core:** BabyCoin, activities, provider roles, VRF task activation, purchases, completion authority, certificates, and an Ignition deployment module.
2. **Stitch UI integration:** canonical Chinese home, marketplace, parent dashboard, provider console, transaction states, and evidence page backed first by typed adapters.
3. **Identity and off-chain data:** Privy, challenge-sign-verify, Cloudflare Worker/D1 task metadata, comments, profiles, and completion records.
4. **Oracle and indexing:** current Chainlink completion workflow, The Graph subgraph, and independent Infura/Alchemy evidence reads.
5. **Testnet delivery:** Sepolia contracts, verified source, Uniswap v3 test pools, Cloudflare deployment, end-to-end QA, screenshots, transaction hashes, and architecture evidence.

Each phase gets its own detailed plan before code in that phase. Do not deploy while a local or test-environment P0 is open. Do not push unless the user explicitly requests it.
