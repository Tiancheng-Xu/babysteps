1. 先补访客推荐模型与本地存储失败测试。
2. 实现固定枚举、阶段任务推荐和安全 localStorage 适配器。
3. 先补首页访客旅程组件测试，再实现选择、开始、完成与登录后续入口。
4. 调整首页 Hero 和进阶 Web3 折叠区，并补页面语义测试。
5. 调整任务、家长中心、个人中心与导航文案；补无钱包可继续 CTA 回归测试。

9. 提交功能分支、推送、创建 PR，等待远端 Gate 与 Cloudflare Preview。
10. 合并到 main，由 Cloudflare Pages Git Integration 发布；核验生产 URL、深链、Evidence、媒体、提交对应关系与 TLS。
