# Sepolia 源码验证入口设计

## 目标

在 BabySteps 页面中提供一个清晰、可核验的公开入口，让访客能够直接查看当前部署合约在 Sepolia Etherscan 上的已验证源码。

## 界面位置

入口放在页面底部“核心技术能力”区域的“链上交互说明”卡片中。该位置用于解释产品的链上实现与公开证据，语义上比首屏品牌区或钱包操作区更合适，也不会干扰连接钱包、记录活动和赠送成长星等主流程。

## 交互设计

- 链接文案为“在 Sepolia 查看已验证源码”。
- 目标地址为 `https://sepolia.etherscan.io/address/0xeb7216D50a2708a59fef5322e452e34382aFCDaD#code`。
- 链接在新标签页打开。
- 使用 `rel="noreferrer"`，避免向目标页面传递来源信息。
- 复用现有 `explorer-link` 视觉样式，保持全站一致，不新增独立组件或设计语言。

## 边界

- 不改变合约地址、ABI、钱包连接或链上交互逻辑。
- 不增加部署、验证或重新验证操作。
- 不展示私钥、RPC、API Key 或其他凭据。
- 不把入口扩展为多链浏览器选择器。

## 验收标准

1. 页面底部存在且仅存在一个“在 Sepolia 查看已验证源码”入口。
2. 链接指向指定合约的 `#code` 页面。
3. 链接包含新标签页和安全来源隔离属性。
4. 现有页面流程、公开文案扫描、测试、类型检查和生产构建保持通过。
